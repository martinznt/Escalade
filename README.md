# Séance Entraînement — fichiers d'architecture V4.1

Ce ZIP contient uniquement les fichiers et dossiers à AJOUTER à la V4 existante
pour préparer les futures évolutions.

Il n'est pas destiné à remplacer le projet V4 complet.

Important :
1. Ne pas supprimer `functions/` tant que l'ancienne architecture n'a pas été vérifiée et remplacée par la V4.
2. Ne pas remplacer `worker.js`, `wrangler.json` ou les migrations existantes avec ce ZIP.
3. Après copie, installer les dépendances puis lancer les tests.
4. Les nouvelles tables D1 devront être créées dans de nouvelles migrations après vérification du schéma réel.
